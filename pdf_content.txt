2. Core Interaction Signals (Replacement for Core Web Vitals)
2026 Metrics (replacing CWV):
Core Interaction Signals:
    Interaction Latency: < 300ms (was INP < 200ms)
    Visual Stability: < 0.15 CLS (relaxed from 0.1)
    Content Paint: < 3.5s LCP (relaxed from 2.5s)
    Real User Experience (RUX)
        Actual user device performance
        Actual user network conditions
        Actual user interaction patterns
    Core Interaction Signals are now COMBINED score
    (not individual metrics)

How to Rank in AI Search:
1. Be in top 10 for traditional search
2. Have original data/research
3. Clear expert credentials
4. Unique perspective on topic
5. Comprehensive coverage
6. High-quality writing
